# 桌面界面优化记录 · 2026-11-10

桌面界面已按现有产品做整体打磨，并根据“整体色彩偏淡”的反馈加强蓝色强调、图表饱和度、状态色和表面层次。保留现有页面入口、功能、内容顺序、深浅主题、模型卡片布局和模型选择菜单的完整名称显示。

设计方法采用 [unslop by Damir Sokolovsky](https://github.com/heydamir/unslop)，遵循 CC BY 4.0 署名要求，并结合工程内 frontend、floating-ui、model-selection 和 i18n 规范。安装位置为 `C:/Users/unittec/.codex/skills/unslop/SKILL.md`。

## 设计方向

- 产品：让使用 Cursor 的开发者配置自有模型、验证连接，并观察实际调用。
- 性格：精确、可靠、鲜明。
- 环境：本地连接控制台；深色使用石墨背景与分层面板，浅色使用冷灰背景与白色卡片。
- 重点：用量趋势、当前选择与连接证据。蓝色表示操作和选择，绿色表示已验证状态及年度用量。
- 识别细节：小状态点与状态文字配对，导航选中项使用蓝色表面和左侧标记。

## 已处理的问题

| 问题 | 修改结果 |
| --- | --- |
| 导航彩色图标来自不同风格 | 统一使用已有 MDI 单色图标；保留 Cursor 和提供商品牌标识 |
| 普通标题大小、字重不一致 | 页面、面板和弹窗标题统一 base 字号与 500 字重；大字号用于指标数值 |
| 浅色说明文字和主按钮对比不足 | 统一主、次、辅助文字；双主题说明文字及主按钮达到 4.5:1 的回归要求 |
| 成功状态引用了未定义的主题变量 | 两个主题都补齐成功、错误和警告语义颜色；诊断和能力结果使用状态点与文字 |
| 控件高度、圆角和间距不统一 | 常规控件 32px，紧凑控件 24/28px，导航 36px；统一控件和卡片圆角与间距 |
| 最小窗口概览筛选遮挡标题 | 1000px 及以下显示时间范围选择框，保留五个预设、自定义范围和模型多选 |
| 自定义筛选打开后键盘焦点留在触发器 | 焦点进入输入框，关闭后返回当前可见的触发器；Escape 分层关闭嵌套菜单 |
| 筛选浮层跨宽窄窗口后仍依赖原触发器 | 监听布局断点，窗口缩放后通过 Floating UI 重新绑定可见触发器 |
| Canvas 图表保留旧主题颜色 | 图表统一读取已解析主题颜色，监听主题变化后重绘，包括缓存中的页面 |
| 系统减少动态效果设置未覆盖界面 | 控件取消过渡，图表禁用动画；保留可见状态和全部操作 |
| 取消与保存同时突出 | 弹窗取消使用次按钮，保存使用主按钮；连接诊断和批量能力测试明确主操作 |

## 九项视觉调整

| 项目 | 实施内容 |
| --- | --- |
| 间距 | 页面边距 20/24px，诊断与插件卡片 16/20px，相关项使用 4/8/12/16px 节奏；保留小控件必要的细微校正 |
| 配色 | 增强主蓝色、导航选中状态、成功绿色与警告琥珀色；拉开背景、卡片、输入区的明暗差 |
| 图标 | 导航统一图标家族、尺寸和文字颜色，供应商品牌标识保留 |
| 文案 | 保留原有功能说明与三种语言；复用现有翻译，没有增加未翻译的用户文案 |
| 字体 | 沿用现有字体及字号变量，普通标题 14px/500；指标使用等宽数字 |
| 布局 | 保留固定窗口栏、固定侧栏、页面操作区与虚拟滚动；补齐窄窗口筛选 |
| 细节 | 控件尺寸、按钮层级、焦点环、悬停行、表格键盘焦点和状态表达保持一致 |
| 视觉 | 保留全部 Token 系列、缓存仪表和年度热力图；提高有实际含义的数据颜色饱和度 |
| 动效 | 控件使用统一缓动；支持减少动态效果，保留加载和下载的状态反馈 |
