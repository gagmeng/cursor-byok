# cursor-byok 工程评审 · 2026-11-10

评审基于 `aefdb9e6`（桌面版 1.1.2）。结论：工程已经具有完整的本地后端、模型管理、插件与 Agent 能力，但存在可复现的会话恢复、模型引用、配置生命周期及管理接口访问缺陷。优先补齐这些行为边界，再增加连接诊断、调用检索、备份恢复和模型健康能力。

后续实现已修复本文 D01–D11，并集成首次使用与连接诊断、模型健康与能力测试。修复行为、实际目录和验证结果见 [修复与功能验收记录](./engineering-fixes-2026-11-10.md)。下文保留评审时的证据与建议快照。

本轮没有修改业务代码。审阅范围为已纳入版本控制的应用源码、测试和 CI；工作区原有未跟踪的 `.claude/`、`apps/docs/` 保持原样。复现使用独立临时数据目录、虚拟密钥与临时 Cursor 设置，没有对真实 Cursor 执行接管、安装 CA 或发送模型请求。

**已有实现的优点与尚未覆盖的风险**

- 会话、传输、运行、工具和协议适配已有独立模块，目录边界基本清楚。检查点恢复、前缀稳定性、取消、工具完成、压缩和事务失败具有实际行为测试。
- SQLite 使用 WAL、显式写协调与 `BEGIN IMMEDIATE`；失败事务连接会关闭，已有恢复测试。插件 JSON 持久化有原子替换及 Windows 短暂锁重试。
- 桌面与管理 API 使用同一 HTTP 来源，便于诊断及外部详情页；前端已有共享虚拟列表、模型选择、主题、翻译和浮层控件。
- CI 当前没有执行 `apps/desktop/src/features/models/*.test.mjs`，也没有执行 6 个内置插件的 Deno 测试；`npm run check` 只做类型检查和构建。界面测试需要外部演示 URL 与未在桌面依赖中声明的 Playwright 环境，默认会跳过。详见 `.github/workflows/ci.yml:65`、`:68`。
- Remote SSH 文档明确记录实际 SSH 会话、远程工具、Tab、Commit 仍待实机验证；本轮没有把单元测试或本地连通性当成 SSH 成功的证据，见 `docs/remote-ssh.md:50`。
- 内置模型默认请求超时为 1 小时、流空闲超时为 30 分钟，运行重试为固定 5 秒、最多 8 次。当前没有分离用户可理解的连接、首个有效响应、流中断与重试总预算；模型发现客户端也未设置独立超时。弱网或提供商异常时容易表现为长时间等待。
- 长期数据治理还不完整：调用与追踪记录主要依赖手动清理，详细追踪关联的 blob 会阻止过期回收；清理后不一定立即缩小物理文件。`maintenance.rs:206` 用整库大小作为估计可回收字节，也可能在大库仅删除少量数据时触发整库 VACUUM。需要在真实数据库副本上测量后再调整，不能仅凭行数判断空间收益。
- 连通性测试只覆盖短文本生成，不能证明工具调用、图片、缓存续接与 SSH 运行可用。
